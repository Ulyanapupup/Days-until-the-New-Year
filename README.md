# Days until the New Year

## 1. Требования для запуска

Требуется установленный Go версии 1.27.1 или совместимой версии.

## 2. Способ сборки

Для сборки проекта перейдите в каталог `lab1` и выполните команду:

```bash
go build ./...
```

Команда собирает все пакеты проекта.

## 3. Способ запуска

1. Откройте терминал.
2. Перейдите в каталог `lab1`.
3. Выполните команду:

```bash
go run .
```

4. После запуска сервер будет доступен по адресу:

```text
http://localhost:8080
```

## 4. Способ запуска тестов

Для запуска тестов перейдите в каталог `lab1` и выполните команду:

```bash
go test ./...
```

Команда запускает unit-тесты функции расчёта дней до Нового года и интеграционные тесты HTTP API.

При отправке изменений в ветку `main` тесты автоматически запускаются через GitHub Actions.

## 5. Предоставляемый HTTP API

Приложение предоставляет HTTP API для расчёта количества дней от указанной даты до 1 января следующего года.

Для выполнения расчёта используется GET-запрос:

```text
GET /days
```

Если дата не указана, приложение использует текущую дату.

Пример запроса без даты:

```text
GET /days
```

Для расчёта относительно определённой даты используется необязательный параметр `date`:

```text
GET /days?date=2026-01-01
```

## 6. Формат входных параметров

HTTP API принимает необязательный параметр `date`.

Параметр `date` должен содержать дату в формате `YYYY-MM-DD`.

Например:

```text
2026-01-01
```

Если параметр `date` отсутствует, используется текущая дата.

Если дата указана в неправильном формате, приложение возвращает ошибку с HTTP-статусом `400 Bad Request`.

## 7. Формат ответа

При успешном выполнении запроса приложение возвращает ответ в формате JSON.

Пример:

```json
{
    "date": "2026-01-01",
    "days": 365
}
```

Поле `date` содержит дату, использованную для расчёта.

Поле `days` содержит количество дней от указанной даты до 1 января следующего года.

При передаче некорректной даты приложение возвращает HTTP-статус `400 Bad Request` и JSON с сообщением об ошибке:

```json
{
    "error": "invalid date"
}
```
